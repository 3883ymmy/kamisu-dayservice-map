# kamisu-dayservice-map

神栖市内の放課後等デイサービスを、住所・現在地・地図上で指定した位置から探すためのWebアプリです。

GitHub Pages：
https://3883ymmy.github.io/kamisu-dayservice-map/

## 主な機能

- 神栖市内の放課後等デイサービス18施設を地図上に表示
- 住所検索
  - 国土地理院の地名検索APIを利用
  - 「神栖3丁目」のような入力でも神栖市内の住所として検索
- 端末の現在地から検索
- 地図上をタップして仮位置を指定
- 指定した地点から近い3施設を直線距離順に表示
- 施設名・住所・電話番号・直線距離を表示
- iPhone / iPad / Mac等で地図を拡大・縮小・移動
- ピンチズーム、ドラッグ移動、全体表示
- 電話番号をタップして発信
- 検索結果をA4縦1枚に印刷
  - 指定地点と最寄り3施設が入る範囲へ印刷地図の縮尺を自動調整
  - 検索地点を青い★、最寄り3施設を赤い1〜3で表示
  - 地図、施設名、住所、電話番号、直線距離を1ページにまとめて出力

## 地図表示

通常の画面表示は、神栖市全図を複数段階のWebPタイルに分割した方式です。

- 画面サイズ・拡大率・端末の画面密度に応じて必要な解像度のタイルを読み込みます。
- 拡大・移動時は、表示範囲周辺のタイルだけを使用します。
- 施設ピンと検索地点は背景地図とは別レイヤーで描画し、地図の拡大・移動に追従します。
- 印刷時は検索地点と最寄り3施設の範囲を高解像度タイルから生成し、A4用の地図として使用します。

背景地図は、国土地理院の地図データを加工して作成しています。

## 検索と距離

住所検索では、入力内容を国土地理院の地名検索APIへ送信し、取得した緯度経度を地図上の位置へ変換します。

最寄り施設の順位は、指定地点と各施設の緯度経度から求めた直線距離で判定します。

道路距離・所要時間・送迎経路を示すものではありません。

## 印刷

住所・現在地・地図上の仮位置のいずれかを指定したあとに「印刷」を押すと、検索結果をA4縦1枚にまとめます。

印刷用地図は、指定地点と最寄り3施設の位置関係に応じて自動的に縮尺を調整します。

施設が密集している地域では建物や道路が確認しやすいように拡大し、施設間の距離が離れている地域では4地点が収まるように表示範囲を広げます。

## 掲載施設情報

放課後等デイサービスの施設情報は、神栖市「やさしい福祉 令和8年度版」70〜71ページを参考に整理しています。

- 掲載施設数：18施設
- 掲載情報の最終確認日：2026年9月26日
- 地図検索で確認できなかった施設については、公開情報を照合して住所を修正しています。
- 施設の追加・廃止・移転・名称変更などを確認した場合は随時更新します。

本アプリは神栖市の公式サービスではありません。

最新の指定状況、利用可否、空き状況、送迎範囲などは、神栖市または各施設へ確認してください。

## 個人情報

- 入力した住所や現在地はGitHubへ保存しません。
- 現在地は端末のブラウザ内で最寄り施設の計算に使用します。
- 住所検索時は、ブラウザから国土地理院の地名検索APIへ入力住所を送信します。
- 検索結果をサーバー側へ保存する機能はありません。

## 対応環境

主にiPhone、iPad、MacのSafariで動作確認しています。

GitHub Pages上で動作する静的Webアプリで、専用サーバーやデータベースは使用していません。
