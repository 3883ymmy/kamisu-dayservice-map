# kamisu-dayservice-map

神栖市内の放課後等デイサービスと、入力した住所との位置関係を確認するためのWebアプリです。

## 目標

- 住所を入力して自宅位置を地図上に表示する
- 神栖市内の放課後等デイサービスを地図上に表示する
- 自宅から近い3施設を直線距離順に表示する
- iPadで地図を拡大・縮小・移動できるようにする
- 検索結果をA4で印刷できるようにする

## 現在できていること

- iPad向けの画面レイアウト
- A4印刷用レイアウト
- 施設データ18件の住所・座標データ
- 18施設すべてを使った直線距離計算
- 背景地図に座標を重ねるためのWeb Mercator変換
- 地図の拡大・縮小・ドラッグ移動の土台

## 次の工程

1. Workウオで作成した神栖市全図を `assets/kamisu-map.png` として追加
2. 背景地図の正確な north / south / west / east を `config.js` に設定
3. 個人住所の扱いを確認したうえで住所検索サービスを選定・接続
4. 実機iPadで表示・印刷をテスト
5. GitHub Pagesで公開

## 掲載情報の出典・更新方針

- 放課後等デイサービスの施設情報は、神栖市「やさしい福祉 令和8年度版」70〜71ページを参考に作成しています。
- 背景地図は、国土地理院の地図データを加工して作成しています。
- 地図検索で確認できなかった施設については、公開情報を照合して住所を修正しています。
- 掲載情報の最終確認日：2026年9月26日
- 施設の追加・廃止・移転・名称変更などを確認した場合は、随時更新します。
- 本アプリは神栖市の公式サービスではありません。最新の指定状況・利用可否・空き状況・送迎範囲などは、神栖市または各施設へご確認ください。
- 表示する距離は直線距離です。

## 個人情報

- 現在地や入力した住所はGitHubへ保存しません。
- 現在地は端末のブラウザ内で最寄り施設の計算に使用します。
- 住所検索サービスを接続する際は、入力住所が外部事業者へ送信される点を確認してから採用します。
